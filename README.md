# Network Security Labs 🌐🔐

Repositório criado para documentar minha evolução prática em Redes de Computadores e Segurança da Informação através de laboratórios realizados em ambiente virtual.

O objetivo é desenvolver uma base sólida em fundamentos de redes, protocolos de comunicação, diagnóstico de conectividade, análise de tráfego e conceitos utilizados em ambientes corporativos de Segurança da Informação.

---

# Sobre o Projeto

Este repositório reúne laboratórios práticos desenvolvidos em ambientes de rede, documentando:

- conceitos de redes;
- protocolos utilizados;
- comandos e ferramentas;
- análises realizadas;
- evidências práticas;
- aprendizados obtidos.

A abordagem utilizada é baseada em resolução de problemas, análise técnica e investigação de comunicação entre sistemas, simulando situações encontradas em ambientes reais.

# Laboratórios

## 🌐 Lab 01 — Fundamentos de Redes e Modelo TCP/IP

### Objetivo

Compreender os fundamentos da comunicação em redes de computadores, analisando como dispositivos trocam informações através dos protocolos de rede.

### Conceitos praticados:

- modelo TCP/IP;
- camadas de comunicação;
- encapsulamento;
- protocolos de rede;
- endereçamento;
- comunicação entre hosts;
- portas e serviços.
